# MIMIC-SQL: SQL Analysis on MIMIC-III Dataset

This project demonstrates SQL-based analysis and querying of the MIMIC-III clinical database for healthcare insights.

## Overview

The project focuses on:
- Writing and executing SQL queries on MIMIC-III data
- Extracting meaningful clinical insights through database operations
- Demonstrating SQL techniques for healthcare data analysis

## Contents

- `MIMIC SQL Presentation Submission.pptx`: Presentation containing SQL queries and analysis results
- `Dataset used.png`: Image showing the MIMIC-III dataset structure

## Dataset

This project uses the MIMIC-III (Medical Information Mart for Intensive Care III) dataset, which contains de-identified health-related data associated with over forty thousand patients who stayed in critical care units of the Beth Israel Deaconess Medical Center between 2001 and 2012.

## Presentation

The main content is presented in the PowerPoint file, which includes:
- SQL query examples
- Data analysis results
- Clinical insights derived from the database

## Requirements

- Access to MIMIC-III dataset (available from PhysioNet)
- SQL database management system (e.g., PostgreSQL) for running the queries
- Presentation software to view the .pptx file

## Note

The MIMIC-III dataset requires credentialed access through PhysioNet. Please ensure you have proper authorization before attempting to replicate the analyses.
